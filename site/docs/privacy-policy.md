# WinSweep Privacy Policy

Last updated: May 26, 2026

WinSweep is designed as a local Windows desktop utility. The project does not
include telemetry, analytics, advertising, or background reporting.

## Desktop app

WinSweep runs locally on your Windows computer. It reads installed app metadata,
uses winget and Microsoft Store sources for update checks, uses the Windows
Update Agent to list pending system updates, scans selected system locations for
residual files, reads relevant registry locations, and registers a Windows
Scheduled Task when you enable scheduled cleanup.

The app does not send app lists, file paths, registry keys, cleanup results, or
settings to WinSweep developers.

The app can invoke tools and Windows services that may contact Microsoft or
package sources, including winget, Microsoft Store sources, and Windows Update.
Those services are governed by their own terms and privacy policies.

## Website

This static website does not set cookies, run analytics, or load external
tracking scripts. If hosted on GitHub Pages, GitHub may process standard server
logs for security, reliability, and abuse prevention.

## Downloads

Installers are distributed through GitHub Releases. GitHub may record access to
release pages and downloaded files according to GitHub policies.

## Contact

Open an issue on the WinSweep GitHub repository for privacy questions or
corrections.
