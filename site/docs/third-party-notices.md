# Third-Party Notices

WinSweep is built with open-source and platform technologies:

- Tauri 2 for the Windows desktop shell.
- React 19 and TypeScript for the frontend.
- Vite for development and builds.
- Tailwind CSS for app styling.
- Rust for Tauri commands.
- lucide-react for application icons.
- winget and Microsoft Store sources for package update detection.
- Windows Update Agent for system update listing.
- Windows Scheduled Tasks for scheduled cleanup.

The website itself is a static HTML, CSS, and JavaScript site. It does not load
external scripts or analytics.

Dependency licenses should be reviewed from the package lockfiles and upstream
projects before redistribution.
