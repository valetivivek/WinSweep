Desktop app

WinSweep runs locally on your Windows computer. It reads installed app metadata, uses winget and Microsoft Store sources for update checks, uses the Windows Update Agent to list pending system updates, scans selected system locations for residual files, reads relevant registry locations, and registers a Windows Scheduled Task when you enable scheduled cleanup.

The app does not send app lists, file paths, registry keys, cleanup results, or settings to WinSweep developers.

WinSweep can invoke Windows services that contact Microsoft or package sources, including winget, Microsoft Store sources, and Windows Update. Those services are governed by their own terms and privacy policies.
