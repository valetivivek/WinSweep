Development notice

Powerful actions stay visible and confirmed.

WinSweep is in active development. Uninstall, cleanup, AppData removal, and scheduled sweep actions should be reviewed carefully. Files and folders are sent to the Recycle Bin when possible. Registry keys are permanent once removed.

What ships now

Five focused surfaces for keeping a Windows install legible.

01

Installed Apps

Lists installed software with search, category filtering, sorting by name, size, or install date, file location access, individual uninstallers, and bulk uninstall flow.

  • Publisher metadata
  • App icons
  • Bulk selection
02

Updates

Checks winget and Microsoft Store package updates, tracks per-app progress, and surfaces pending Windows Update items with a direct jump to Windows Settings.

03

Cleanup

Auto-scans residual files, folders, and registry keys across AppData, ProgramData, Temp, and Registry. Nothing is deleted until the user confirms the selected paths.

04

App Data

Finds AppData and ProgramData folders that map to software still installed, then lets you reveal, sort, and move selected folders to the Recycle Bin.

05

Settings

Registers a Windows Scheduled Task for weekly unattended cleanup of Temp, Recycle Bin, and app caches. Quick Sweep can run the same selected categories immediately.

Cleanup model

Scan broadly, select deliberately, delete only after confirmation.

1

Scan on open

Cleanup starts when the page opens and checks AppData, LocalAppData, ProgramData, Temp, and Registry. Progress stays visible during the scan.

2

Review grouped results

Results are grouped by related app and tagged as Logs, Cache, Config, Data, Crashes, Installer, or Other. Search works across path, extension, kind, size, and metadata.

3

Confirm destructive work

Selected files and folders go to the Recycle Bin where possible. Registry cleanup is called out before confirmation because registry keys are removed permanently.

Privacy, license, safety

The small print is short on purpose.

Privacy policy

WinSweep does not include telemetry, analytics, ads, or background network reporting. The app runs locally and invokes Windows, winget, Microsoft Store sources, Windows Update Agent, registry reads, file scans, and scheduled task registration only for the features the user starts or configures.

Safety notes

Nothing is auto-deleted. Cleanup and AppData removal require explicit confirmation. Registry items are permanent once removed, so the UI labels those stakes before the action continues.
